# Contributing

Contributions are warmly welcome.
Found a typo? Want to help us out? We would like you to help us improving the website!

# AI Policy

- Do not use LLMs to generate substantial pieces of code or documentation.
  - All decisions need to be made by a human, and the code needs to be fully understandable by the committer.

- Do not use LLMs for human-to-human communication.

- Usage of LLMs for machine translation and spellchecking is acceptable as long as the original text has been written by a human. In these cases, include the original text and a line that it has been machine translated.
